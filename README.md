# SYLENTH AI Agent 🤖

Ushbu bot Telegram chatlarini avtomatlashtirish uchun Llama 3.3 (Groq API) modelida ishlaydi.

## 🚀 Imkoniyatlar
* **24/7 Ishlash:** GitHub Actions orqali uzluksiz ishlaydi.
* **Aqlli muloqot:** Groq Cloud platformasining eng kuchli modellari bilan bog'langan.
* **Xavfsizlik:** API kalitlar GitHub Secrets orqali himoyalangan.

## 🛠 Texnologiyalar
* Python 3.10+
* Aiogram 3.x
* Groq SDK

## ⚙️ O'rnatish
1. Repozitoriyani "Fork" qiling.
2. GitHub Secrets-ga `BOT_TOKEN` va `GROQ_KEY` kalitlarini qo'shing.
3. Actions bo'limidan botni ishga tushiring.
